# Alke Wallet

Proyecto desarrollado para el Módulo 2 Fundamentos del Desarrollo Frontend

Alke Wallet es una billetera digital que permite simular distintas operaciones financieras mediante una interfaz sencilla e interactiva

## Funcionalidades

- Inicio de sesión
- Visualización del saldo disponible
- Depósito de dinero
- Retiro de dinero
- Envío de dinero
- Recepción de dinero
- Agenda y búsqueda de contactos
- Historial de últimos movimientos
- Filtro de transacciones
- Actualización dinámica del saldo

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Bootstrap
- jQuery
- Local Storage
- Git
- GitHub
